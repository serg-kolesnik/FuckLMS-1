# FuckLMS

> Навёл камеру на QR-код — и посещаемость отмечена.

**FuckLMS** — система для студентов, которая избавляет от ручной отметки присутствия на занятиях в электронной системе университета ([lms.uni-dubna.ru](https://lms.uni-dubna.ru)). Состоит из Android-приложения и собственного Go-сервиса.

Приложение сканирует QR-код посещаемости, а сервис входит в систему и отмечает присутствие — для одного или сразу нескольких сохранённых студентов, параллельно.

## Возможности

- 📷 **Сканер QR-кодов** — наведите камеру на код с экрана или проектора, ссылка распознаётся мгновенно
- 👥 **Студенты в общей базе** — список хранится на вашем сервисе (PostgreSQL); работайте с одного или нескольких устройств
- ⚡ **Параллельная отметка** — сервис входит в LMS и отмечает выбранных студентов одновременно: секунды вместо минут
- 🔒 **Пароли не на телефоне** — приложение хранит только адрес сервиса и токен доступа; учётные данные студентов живут в БД сервиса
- 🏠 **Всё своё** — сервис работает на вашем сервере или ПК; между телефоном и LMS нет чужих посредников

## Как пользоваться

### 0. Разверните сервис

Поднимите FuckLMS-сервис (`server/`, Go + PostgreSQL) на своём сервере или ПК — см. [docs/adr/0001-go-attendance-service.md](docs/adr/0001-go-attendance-service.md). В настройках приложения укажите адрес сервиса и токен доступа.

### 1. Добавьте студентов

Откройте вкладку **«Аккаунты»**, введите имя, фамилию, группу, логин и пароль от LMS и нажмите **«Добавить»**. Студент сохранится в базе сервиса. Повторите для каждого, кого планируете отмечать.

### 2. Выберите студентов

Галочками отметьте, для кого нужно проставить посещаемость. Снимите галочку — и студент будет пропущен.

### 3. Отсканируйте QR-код

Перейдите на вкладку **«Сканер»** и наведите камеру на QR-код посещаемости. Ссылка распознается автоматически, и приложение сразу перейдёт на вкладку **«Отметка»**.

### 4. Дождитесь завершения

Сервис параллельно для каждого выбранного студента:

1. входит в LMS под его логином и паролем;
2. проверяет, не отмечена ли посещаемость ранее;
3. выбирает статус «присутствовал» и сохраняет.

Результаты приходят на экран по мере готовности — живым списком *«логин → статус»*. Когда всё готово, появится сводка: сколько отмечено, сколько уже были отмечены раньше и сколько ошибок.

> Если посещаемость по студенту уже была отмечена раньше — сервис распознает это и вернёт статус «уже отмечена». Это тоже считается успехом.

## Требования

- Телефон на **Android 7.0** (API 24) или новее
- Камера (разрешение запрашивается при первом запуске)
- Подключение к интернету
- Развёрнутый FuckLMS-сервис (`server/`: Go + PostgreSQL) с доступом к [lms.uni-dubna.ru](https://lms.uni-dubna.ru)
- Учётная запись в [lms.uni-dubna.ru](https://lms.uni-dubna.ru)

## Установка

### Из исходников

Понадобится [Android Studio](https://developer.android.com/studio) (или JDK 17+ и Android SDK):

```bash
git clone https://github.com/slipynil/FuckLMS.git
cd FuckLMS
./gradlew assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk` — скопируйте его на телефон и установите, разрешив установку из неизвестных источников. Либо просто откройте проект в Android Studio и нажмите **Run ▶**.

Для полноценной работы также разверните сервис (каталог `server/`, Go + PostgreSQL) — инструкция появится вместе с кодом сервиса; архитектурное решение описано в [docs/adr/0001-go-attendance-service.md](docs/adr/0001-go-attendance-service.md).

## Приватность

- Учётные данные студентов хранятся **только в базе данных вашего сервиса**; приложение хранит лишь адрес сервиса и токен доступа.
- Пароли передаются в сервис только при добавлении или изменении студента; при отметке по сети уходят только идентификаторы студентов и QR-ссылка.
- Сервис обращается исключительно к `lms.uni-dubna.ru` и к своей базе; между телефоном и LMS нет сторонних сервисов.
- ⚠️ Пароли в БД сервиса хранятся в открытом виде (осознанное решение, см. [docs/adr/0001-go-attendance-service.md](docs/adr/0001-go-attendance-service.md)) — ограничьте доступ к серверу и базе данных, используйте LAN или TLS.

## Частые вопросы

**Появилось «Нет выбранных студентов!»**
Отметьте галочкой хотя бы одного студента на вкладке «Аккаунты».

**Приложение не подключается к сервису / ошибка сети**
Проверьте в настройках адрес сервиса и токен, доступность сервиса (`GET /health`) и что телефон и сервер в одной сети (или сервис доступен извне).

**Студент получил статус «ошибка»**
Чаще всего неверный логин/пароль или QR-код устарел. Проверьте данные на вкладке «Аккаунты» и отсканируйте QR заново.

**Можно отметить только одного студента?**
Да — снимите галочки со всех остальных, либо отметьте конкретный список в запросе.

**Придётся каждый раз вводить пароль заново?**
Нет. Студенты сохраняются в базе сервиса и выбираются галочками.
