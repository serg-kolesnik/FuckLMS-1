FuckLMS — схема работы приложения

Целевая архитектура (ADR 0001): приложение состоит из трёх вкладок — «Сканер», «Отметка» и «Аккаунты» — и является клиентом отдельного Go-сервиса. Студенты хранятся в PostgreSQL на сервисе; сервис сам входит в Moodle LMS и отмечает присутствие параллельно для всех выбранных студентов, отправляя результаты потоком Server-Sent Events. Прежняя WebView-автоматизация и локальное хранение аккаунтов удалены.

Компоненты

Компонент Где Технология Роль
Сканер QR MainActivity.kt → ScannerScreen() CameraX + ML Kit Barcode Считывает QR-код и передаёт сырую ссылку на экран «Отметка»
Экран отметки MainActivity.kt → MarkingScreen() OkHttp + разбор SSE-потока Отправляет POST /api/mark и показывает живой статус по каждому студенту
Аккаунты (студенты) MainActivity.kt → AccountsScreen() CRUD-запросы к сервису Список студентов из БД сервиса, галочки isSelected
Настройки сервиса EncryptedSharedPreferences (отдельный ключ) AES-256 Только URL сервиса и bearer-токен; пароли на телефоне не хранятся
Go-сервис server/ net/http, пул воркеров CRUD студентов, параллельный логин и отметка в Moodle, SSE-стрим результатов
База данных server/migrations/0001_init.sql PostgreSQL, таблица students Единственное хранилище аккаунтов (имя, фамилия, группа, lms_login, lms_password)

Основной поток

flowchart TD Start([Пользователь открывает приложение]) --> Cfg["Настройки: URL сервиса + bearer-токен
(вводятся один раз)"] Cfg --> Acc["«Аккаунты»: список студентов из БД сервиса

status = success"] Res -- "already / уже отмечен" --> EvAlready2["SSE result:
status = already"] Res -- прочее --> EvErr["SSE result:

event: result … event: done
+ heartbeat : ping"] EvOk --> Stream EvAlready2 --> Stream EvErr --> Stream Stream --> UI["MarkingScreen: живой список

успешно / уже были / ошибки"] Done --> Finish(["Все результаты показаны"])

Пароль из QR-кода и sessid извлекает сервис (приоритет параметров: qrpass → password → studentpassword). Приложение передаёт сырую ссылку целиком. Статусы: success — отмечено, already — уже было отмечено раньше (считается успехом), error — сбой этого студента, остальные продолжают обрабатываться.
